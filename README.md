## 1. Project Description

- **Phone catalog**: This project is a website selling electronics such as phones, watches, and tablets. The site is fully responsive and adaptable to various devices. It features pages such as a homepage with information about the products available on the site. A catalog page displays various devices based on product category. The catalog page also features an intuitive and user-friendly interface, allowing users to sort products by specific criteria or select the number of items per page. A product detail page allows users to select the product's color, storage capacity, and a detailed description. The site also allows users to add products to their cart or favorites, so they won't be lost when they reload the site or exit.

## 5. Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/10hokageee/react_phone-catalog-mykyta-serdiukov.git
   cd react_phone-catalog-mykyta-serdiukov
   ```

2. **Install dependencies:**

   ```bash
   npm install
   # or
   yarn install
   ```

3. **Run the project locally:**

   ```bash
   npm start
   # or
   yarn start
   ```

## 6. Features

- **Responsive Design** - The site is adaptive for different types of devices: 345px, 639px, 1199px.
- **Navigation** - The site uses react-router-dom for navigation, which allows you to switch between pages.
- **Favorites & Cart** - Pages that allow you to add products to your favorites or cart.
- **Sorting Products** - The catalog's sorting features allow you to sort by criteria such as Newest, Alphabetically, Cheapest.
- **Product Filtration** - Filter products by color and memory size on the product detail page.
- **Search Parameters** - Filter products using query parameters.
- **Pagination** - Ability to scroll through pages on the catalog page. 
- **Sticky Header** - Fixes the header at the top, allowing you to see it when scrolling.
- **Scroll to Top Button** - When clicked, scroll to the top of the page.
- **Loader** - Loading when interacting with pages.
- **Swiper Carousel** - Image slider.
- **Items on Page** - Allows you to select the number of products per page on the catalog page.
- **User Action Pseudo-classes** - Hover effects.
